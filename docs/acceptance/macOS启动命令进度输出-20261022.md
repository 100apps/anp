# macOS 原生启动命令进度输出

`./anp start` 已改为面向人工管理的实时输出，并同步到本机 `var/native/run/anp-macos-arm64` 和构建目录。本轮没有重启用户的实际实例；正在执行的旧启动命令不会因文件更新而改变，下次调用生效。旧压缩包未重新生成。

## 输出内容

- 带时间戳的运行目录、配置文件、数据目录、日志目录和依赖启动顺序。
- 启动前检查主端口及附属端口；占用时显示端口和监听 PID。
- 每个服务的序号、名称、端口、日志路径；创建进程后显示 PID。
- 等待就绪期间约每 5 秒显示等待状态和耗时，就绪后显示本服务耗时。
- 已健康运行的服务显示“复用”，不重启。
- 启动失败显示退出码和日志路径，并输出本次新服务的回滚过程；已有服务保留。
- 完成后输出服务、PID、端口、就绪状态表格，以及访问地址、状态/停止命令和日志位置。
- 生命周期锁被其他启动/停止命令占用时，提示等待和锁文件路径。

进度写入 stderr 并立即刷新。正常结果为 stdout 表格。需要机器读取时用 `./anp start --json`，仅输出 JSON，包含 ready、port、pid。`./anp status` 保留原来的 JSON 输出。

输出不打印环境变量、完整启动参数或密钥。测试中实际检查生成的秘密值未出现在启动输出中。

## 验证范围
