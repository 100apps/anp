## 修复内容

1. 修复 macOS 共享目录上的 PostgreSQL Unix socket chmod 失败：仅运行目录使用 Linux tmpfs，数据库仍在原数据根。验收脚本同步验证 bind 数据挂载与 tmpfs。
2. 工作台使用侧栏以外的全部宽度；手机可展开完整导航，无横向溢出。
3. 失败结果明确显示“运行失败”；切换业务清空旧结果与轨迹，运行时禁止切换。
4. 平台状态每 10 秒更新，容器恢复后无需刷新页面即可恢复“可访问”，卸载时中止请求并清理定时器。
5. 调试验收跳过 multiprocessing 资源跟踪器，附加实际业务子进程；新增辅助进程先到达及进程已退出的回归测试。
6. README、架构指南和配置参考同步补充 macOS 运行目录及资源限制。
