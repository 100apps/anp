# 业务演示

当前业务包含两个图，默认使用确定性离线模型，不调用供应商。

| 图 | 入口 | 验证内容 |
| --- | --- | --- |
| Workflow | business/src/anp_business/workflow_demo/ | 文本清洗、摘要、结束三个节点 |
| Deep Agent | business/src/anp_business/deepagent_demo/ | 架构资料工具调用与报告 |

在仓库根运行 make init、make up、make dev 后，访问 <http://127.0.0.1:51760/workbench/>。两图共用 LangGraph Agent Server 的 HTTP 扩展，不增加业务 HTTP 服务器。真实模型配置见[配置参考](../development/配置参考.md)。

视频译配功能已移除。旧数据库中的业务表、私有桶、媒体和配置没有自动删除或迁移。
