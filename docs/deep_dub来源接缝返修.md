# deep_dub 来源接缝返修

## 范围

来源准备已停在独立复核门禁。原稿在固定分块接缝处可能切词或重复，直接采信官方参考、删除接缝文字或裁剪强制对齐越界值都不能解决声学证据缺口。本阶段从原识别产出的完整 PCM 获取每个接缝前后各六秒，在一次 GPU 租约内使用同一个受控 ASR 进程重新识别，保存额外候选。

这是**改窗且无文本提示的同模型复测**，不是独立内容审核。原稿、原始词时间、来源 ID、原排队时间与待审门禁不变，不登记正式 cue/语义段，也不签发内容、角色、字幕或整片通过。

## 待审返修边界

迁移 `016_source_boundary_recheck.sql` 不增加存储或业务表。待审运行只在以下条件同时成立时允许返修阶段领取租约和写入证据：

- 节点固定为 `source_boundary_recheck`，资源声明为 `gpu`，分区严格等于该运行绑定的来源 ID。
- 原平台任务仍在运行且未请求取消，运行未技术完成，并存在当前冻结的 `source_preparation_review` 待审回执。
- 当前用户仍有运行与审核权限；实际 GPU 探测、文件锁、设备租约、心跳和原执行者身份沿用既有规则。

其他生产节点、错误资源类型和其他来源仍被拒绝。返修阶段不能通过任何候选登记接口换源、封存原文/分段、提交配音或成片；只能保存证据。撤权或取消后不能续租或继续写对象。没有把运行临时改回 `running`，也没有改动最早计时。

五个 PostgreSQL 库在迁移前完成新备份和逐库实际恢复校验；备份位于本机私有 `.local/backups/v3-postgres-before-cloud-20261018T193744Z`。恢复依赖原实例角色，不是重建全局角色或完整跨存储灾难恢复。

## 服务、CLI 与工作台

```powershell
uv run anp deep_dub runs recheck-source-boundaries RUN_ID SOURCE_ID --request-key STABLE_KEY
uv run anp --transport http deep_dub runs recheck-source-boundaries RUN_ID SOURCE_ID --request-key STABLE_KEY
uv run anp deep_dub runs recheck-source-boundaries RUN_ID SOURCE_ID --boundary 18 --request-key ANOTHER_STABLE_KEY
uv run anp deep_dub projects source-boundary-recheck PROJECT_ID SOURCE_ID
```

默认本地 CLI 直接执行同一服务；HTTP CLI/Web 分别使用 `POST /runs/{id}/recheck-source-boundaries` 和 `GET /projects/{id}/sources/{source_id}/boundary-recheck`。`--boundary` 可重复，省略表示全部接缝；编号唯一且必须属于当前 ASR 分块。

服务以 ASR 证据 ID/摘要、PCM、边界编号、模型实际摘要和超时冻结输入。模型不接收原稿或官方参考提示；原前/后块文字只进入结果证据供对照。读取重新验证窗口、输入摘要、模型、原始样本和已停止会话，不能仅凭阶段 `succeeded` 记分。

工作台以 shadcn/ui 展示窗口数量、进程停止状态及前块末尾/后块开头/改窗候选，按需展开更多接缝。执行仍需权限及待审运行，可取消原运行停止执行；同输入重放不重新加载模型。

- TypeScript 与生产制品构建通过；冻结制品 `20261018193745-74633d00` 已经 Compose 重建、完成迁移并真实启动。
- 当前整片的 43 个真实接缝窗口全部识别，提交 8,256,000 个 PCM 样本（516 秒，窗口是局部复测，不是整片耗时比），空候选 0。一次受控模型会话，43 次请求、42 次已加载检查，模型生命周期约 23.656 秒。模型和 FFmpeg 子进程全部实际退出，GPU 租约为 `released` 且 `operation_stopped=true`。受控服务退出码 1 原样保留，不改写为正常退出码 0。
- 真实首次验收在模型、停止、原稿/运行不变及四项评分检查均完成后，因错误预期 Langfuse 的用户身份而失败，完整测试耗时 46.81 秒。失败日志保留，未重跑模型或回填通过。Langfuse 的 `userId` 按事务 outbox 固定为任务发起者，`sessionId` 为运行 ID，阶段的 `attempt_id` 关联此次管理员执行者；不能把执行者与运行发起者混为一谈。
- 同一尝试后续验收 7.37 秒通过：读取实际用户/session 和四项评分，两种 CLI 重放/读取相同冻结结果，模型执行次数保持 43，原待审运行、复核队列摘要、来源、分段与审核状态保持。
- 第 18 个接缝窗口为 `1074–1086s`。原后块以 `States it could be...` 开头；改窗候选重新识别出 `...United States. It could be any history...`。这说明接缝确有需要核对的候选差异，尚不能判定两版哪版完全正确，也没有自动改稿。

首次数据库专项还保留一个测试夹具错误：断言项目完全没有分段集，但基础 seed 已有另一个来源的分段集；已改为精确核对本次来源，未放宽业务约束。
