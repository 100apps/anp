# deep_dub 波形派生产物

## 已运行验证

2026-10-18，正式 V3 制作台的原声窗口、放大后的原声轨及已有声音版本已连接私有波形读取。波形准备通过现有运行阶段和本工作区 CPU 租约执行，不新增数据库表或存储实例，不在 GET 请求里启动解码。

准备过程包含原身份权限检查、同项目验证、完整私有对象下载与 SHA256/大小校验、FFmpeg 解码、PCM 峰值归约、JSON 私有上传、回读校验及带 fence 的阶段提交。长期产物保存在 RustFS；输入与 PCM 临时文件在处理结束后清理。取消和失去租约沿用运行器的子进程停止、结果拒绝与设备释放机制；本轮没有再次做波形专属的中途撤权压力验收。

读取只接受当前规则与输入摘要对应的成功阶段输出，校验唯一输出、执行尝试归属、项目、媒体类型、JSON 大小、样本数和峰值范围；每次仍检查调用者和工作空间。无成功派生结果返回 `WAVEFORM_NOT_READY`，没有音频轨则准备失败为 `WAVEFORM_NO_AUDIO`，均不生成假波形。查看者可以读取已有结果，不能发起计算。

峰值采用第一条音频流、单声道 16 kHz、每 160 样本一个绝对峰值，范围 0–1；保留起始时间偏移对应的静音，不按每段最大值归一化。规则版本为 `pcm-mono16k-100hz-max-v1`。用户窗口再归约为 16–2048 个点；固定 10ms 桶边界不作为精确音素对齐或语音质量证明。当前限制为三小时、派生 JSON 不超过 16 MiB，不隐式截断后声称完整。

| 检查 | 实际结果 |
| --- | --- |
| 真实 PCM 与 FFmpeg | 静音保持 0、半幅样本保持 0.5、部分末桶和不完整 PCM 校验；延迟 0.5 秒的音频保留静音起点；无音频视频拒绝 |
| 真实运行与存储 | 三秒 H.264/AAC 正弦夹具准备成功；JSON 写入 RustFS并经完整摘要回读；同幂等键重放同一阶段，CPU 租约释放 |
| 三入口契约 | HTTP、默认本地 CLI（业务 API 指向不可达端口）与 HTTP CLI 的两秒/64点窗口一致；峰值约 0.125153 |
| 权限 | 查看者读允许、准备 403；未登录 401、外空间拒绝、非法时间窗口 422 |
| 浏览器 | 两秒原声窗口显示 200 峰；点击中点后视频约 1.499053 秒，段内滑块 1 秒、上限 2 秒，窗口起点 0.5 秒 |

首轮真实集成在验收器直读租约表时失败：该表含令牌摘要，不给普通业务身份直接查询。修正验收器，使用独立只读数据库连接只核对停止字段，没有放宽业务权限；重跑通过，原失败日志保留。

证据：[实际记录](evidence/deep-dub-waveform-20261018.json)、[浏览器截图](evidence/deep-dub-waveform-studio-20261018.png)。运行测试使用独立 8184 端口并在结束关闭；浏览器沿用独立 8183/8767 入口，平台容器和旧服务没有重建或接管。

## 使用同一业务契约

```powershell
# 在已启动、允许执行的同项目运行中准备；不是重新设置生产起点。
uv run anp deep_dub runs waveform <运行UUID> <媒体产物UUID> --request-key <UUID>

# 默认本地读取；不需要启动业务 Web API。
uv run anp deep_dub media waveform <媒体产物UUID> --start 0.5 --end 2.5 --points 640
uv run anp --transport http --endpoint http://127.0.0.1:8183 deep_dub media waveform <媒体产物UUID> --start 0.5 --end 2.5 --points 640
```

对应 HTTP：`POST /api/apps/deep_dub/runs/{run}/waveform`，正文为 `artifact_id`、可选 `device_id` 与 `timeout_seconds`，使用 `Idempotency-Key`；读取为 `GET /api/apps/deep_dub/media/artifacts/{id}/waveform?start=0.5&end=2.5&points=640`。只有媒体/运行 UUID，无宿主路径和 URL 令牌。
