# deep_dub Windows 监听归属检查优化

## 问题与实现

完整来源词时间的上一轮真实测量处理44块，模型请求合计13.422秒，但请求前归属和状态核对合计165.221秒。旧实现每次启动 PowerShell 查询 `Get-NetTCPConnection`。

新实现使用 Windows 官方 [GetExtendedTcpTable](https://learn.microsoft.com/windows/win32/api/iphlpapi/nf-iphlpapi-getextendedtcptable)，每次分别读取 IPv4、IPv6 的监听表，收集指定端口全部地址的 PID，要求集合精确等于本次 Popen 进程。查询前后均检查进程仍在运行；未知 PID、混合归属、无监听均拒绝。API失败、缓冲区不完整或持续增长会抛错，不能回退到仅凭健康接口认可归属。没有缓存监听表、PID或授权结果。

业务实现为 `apps/deep_dub/services/listener_owner.py`，由 `model_pool.py` 调用；未增加依赖、存储或后台常驻模型，也没有改变 GPU 白名单与租约、取消和清理规则。当前运行器仅支持 Windows NVIDIA，不宣称 Linux 已通过。
