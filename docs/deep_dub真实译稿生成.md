# deep_dub 真实译稿候选生成

## 已运行验证

2026-10-18，新增 `nodes/translate.py` 与 `services/translation.py`，正式 Web、HTTP 和两种 CLI 共用同一受限服务。没有改变平台镜像或部署拓扑，也没有引入本地模型仓库、额外存储实例。

服务从当前用户可访问的封存原文段读取输入，附带前后各两段原文；原文集合必须与运行的来源一致。上下文、模型名、完整提示版本和超时选项构成输入摘要。上下文超过 128 KiB 拒绝，响应超过 2 MiB 拒绝。原文被作为待翻译资料，不作为平台指令。

默认使用平台 LiteLLM 的 `auto`，可由 `[deep_dub].translation_model` / `ANP_DEEP_DUB_TRANSLATION_MODEL` 更换；禁止选择 `demo-mock`。记录请求模型与网关报告模型、响应 ID、允许的 token 用量、提示版本和上下文/结果私有产物。**本轮网关报告的名称仍是 `auto`，没有核实其底层具体模型，不把路由名当作已证实的实际模型型号。**

响应须为完整 JSON、结束原因为 `stop`、目标段 ID 完全匹配、正文包含非空中文，才追加候选。拒绝截断、英文原文回显、空模型身份、错误段 ID、额外结果字段。这里只验证登记契约，不判定语义、数字、专名或自然度通过。

## 执行、权限和取消

- 需要 `deep_dub.task.run` 与 `deep_dub.audit`；同空间/项目/来源检查在请求模型前执行，最终写入仍由受限 RPC 检查原用户、运行和尝试。
- 通过 `deep_dub_begin_stage` 的 `acquired=true` 领取执行。相同输入的排队/执行中尝试返回当前状态；另一个请求不得因为尝试仍是 queued 就重复启动外部模型。成功输入复用原阶段和候选，不隐式重新调用模型。失败后由明确的新请求键产生重试尝试。
- 此阶段调用已配置的外部模型网关，不领取或伪造本工作区 GPU/CPU 租约。每秒重新检查运行、任务取消和执行/评分权限；客户端取消时关闭本次请求，拒绝晚到提交。不能据此声称上游模型已经停止计算、释放显存或不再计费。
- 超时、连接失败、429 和超大响应被转换为不含上游正文/凭据的错误，不自动重试付费请求。已取消运行不允许重新生成或补写评分，没有为验收放宽该约束。
- 阶段成功后记录 `translation_response_contract=1`，范围仅为响应结构与登记；`translation_semantics` 为 `not_measured`、值为空。Langfuse 实际读回数值契约分与未测文本状态，追踪使用调用用户及 run 会话。没有生成 passed 审核、选版、TTS 或成片。

响应契约评分使用 `zh-context-candidate-v1-response-evidence-v2`：按译稿的上下文外键定位两个私有产物，核验实际响应正文、模型、段、上下文指针及输入摘要，不依赖阶段输出列表顺序。组合回归曾发现数据库将输出 UUID 规范排序，开发版 v1 的位置取证会误指向上下文。已确认的历史错误分 `5717b24d-ac24-449d-bdcd-a1c5edb9fb08` 保留，不删除或覆盖，也不纳入本轮通过证据；新评分使用独立 v2 规则和幂等键。正式质量门禁没有因该开发分而放行：此类验收候选始终没有 passed 审核。

## 正向结果和边界

| 检查 | 结果 |
| --- | --- |
| 实际输入 | 仅读旧工作台的公开 Yale 原片，新截取 26 秒并重新登记；原文取既有资料，不读取旧译稿、选中 WAV 或旧成片。旧 FLV 与项目 URL 的版本身份未独立匹配，没有来源审核通过 |
| 实际网关 | `auto` 返回新中文候选，网关报告名为 `auto`；上下文与结果保存到 RustFS，候选绑定准确段/阶段 |
| 三入口 | 真实 API、本地服务、默认本地 CLI（业务 API 指向不可达地址）与 HTTP CLI 重放同一结果；同输入只有一条候选 |
| 权限 | 查看者 403、未登录 401、外空间拒绝；所有业务写入使用调用者 JWT |
| Web | 未绑定来源时禁用生成；正常登记本轮来源后，从确认对话实际生成并保存候选。旧来源候选保留；取消后刷新，按钮重新禁用 |
| 页面 | 私有原片/640点实际波形与新候选同时可见；段内中点定位原片约 13.028394 秒，原窗为 0.78–25.30 秒 |
| 并发/取消 | 真实数据库验证 queued 重放与运行中重放均不重复调用受控等待函数；取消后本地等待结束、尝试 cancelled、无译稿或评分提交。这是受控提供方，不是实际上游取消证明 |
| 检查 | 33 项模型契约/网关故障/媒体工具检查、1 项真实网关三入口集成（含倒序输出重放与 v2 证据关联）、1 项真实数据库并发取消集成通过；TypeScript 和正式 Vite 构建通过，入口块大小仍有警告 |

实际 Web 候选含“您们”等不妥表述，也存在需要复核的句式。响应结构通过不代表内容通过；本轮没有把该候选记为合格，更没有为消除未测状态回填审核。截图中视频自带的既有字幕属于输入原片，不是本轮生成的字幕或成片。

首轮集成在取消后才尝试重放 CLI，被“运行已停止或取消”拒绝；测试顺序修正为在同一运行仍活跃时比较三入口，之后取消。原失败日志保留，业务停机限制未放宽。

证据见 [接口、并发和页面记录](evidence/deep-dub-translation-20261018.json)、[Web 截图](evidence/deep-dub-translation-web-20261018.png)。独立接口验收使用 8184 并在测试后关闭；浏览器沿用独立 8183/8767 入口。原平台和旧业务服务未被接管。

## 命令

```powershell
uv run anp deep_dub runs translate <运行UUID> <段UUID> --request-key <UUID>
uv run anp --transport http --endpoint http://127.0.0.1:8183 deep_dub runs translate <运行UUID> <段UUID> --request-key <同一UUID>
```

对应 `POST /api/apps/deep_dub/runs/{run}/translate`，正文为 `segment_id` 与可选 `timeout_seconds`（默认 120 秒），请求头为 `Idempotency-Key`。Web 使用同一接口，草稿未保存时禁止触发生成，避免覆盖正在编辑的内容；相同输入复用成功候选，变更原文/上下文/模型/提示版本将形成不同输入。
