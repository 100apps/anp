# deep_dub 私有媒体读取与播放

## 已运行验证

2026-10-18，业务 API 新增私有音视频读取，原生播放器已接入工作台产物详情。未增加存储实例、公开对象链接或平台镜像补丁。

- `GET /api/apps/deep_dub/media/artifacts/{id}/info`：按当前身份与工作空间读取媒体信息，不返回对象存储路径或凭据。根 CLI 使用 `uv run anp deep_dub media info <产物ID>`；默认本地与 HTTP 结果一致。
- `GET /api/apps/deep_dub/media/artifacts/{id}`：支持单个标准字节范围、尾部范围和续读。无效或多段范围返回 416；不匹配的 If-Range 返回完整内容。代理核对上游状态、范围与长度，并在结束、异常或消费取消时关闭自己的 HTTP 响应和客户端。
- 媒体 URL 不携带令牌。浏览器通过 `POST /media/session` 获得最长 180 秒的签名 HttpOnly、SameSite Strict、限定路径的播放会话；签名带独立用途前缀，服务端校验有效期，不只依靠浏览器 Cookie 过期。
- 每次媒体请求重新检查 Supabase 用户、工作空间成员资格和项目读取权限；播放会话不是授权判断缓存。显式错误 Bearer 不会借已有 Cookie 回退为其他身份。
- API 与浏览器实际验证了退出时清理播放会话。切换工作空间也通过通用应用会话清理入口处理，但本轮没有第二工作空间的浏览器切换实测。服务不可用导致清理失败时，原会话最多存活到服务器签名期限；不能声称已经收到的数据可以被撤回。
- 只有白名单音视频类型可以内联播放，HTML 产物返回 415。响应使用 `private, no-store` 和 `nosniff`。流式播放依赖已经完成上传校验的不可变对象；范围读取本身不重新计算整文件 SHA256。

本机 HTTP 开发入口不设置 Secure Cookie；HTTPS 请求设置 Secure。真实云端 TLS/代理部署仍需单独验收，不把本机配置作为公网部署验收。

## 真实浏览器结果

- 两秒验收正弦 WAV 实际播放到结束：duration=2、currentTime=2、readyState=4、无媒体错误。退出后直接访问原媒体 URL，返回 `INVALID_MEDIA_SESSION`；随后恢复工作台登录。
- 三秒 H.264/AAC 测试图视频实际播放到结束，读取到 160×90 画面与三秒时长；通过原生进度条从结尾跳到约 1.43 秒，画面显示相应时间。播放和跳转截图保留。
- HTTP 实测比较了完整字节、前缀、后缀、续读与 If-Range 回退。浏览器小文件已可能完整缓冲，因此不把浏览器跳转当作长片网络续播或性能证明。
- 专用媒体测试账号先获得有效播放会话，再撤销其工作空间成员资格，下一次 Range 请求返回 403。测试后恢复该账号的 viewer 成员身份，没有修改共享角色权限或其他用户。

音频/视频夹具属于不同的明确标记 acceptance 运行；没有使用真实配音、Yale 来源、旧成片或生产 run。浏览器与最后一轮接口验收的产物 ID 可不同，分别保留实际记录。

首轮合并回归曾遇到一秒短期会话在首个请求前已到期：整数秒截断与密钥初始化占用了有效窗口。现先读取密钥，再以精确服务器时间签发；短期验收使用两秒期限。没有延长到用户 JWT 到期之外，也未放宽过期检查。修正后的完整回归已另行保存，失败日志不删除。

## 未完成范围

当前是单媒体原生播放基础。波形持久化、同步多轨 transport、原文/译文分段定位、监听 mute/solo 与生产增益分离、版本编辑、真实长片续播以及整片质量/RTF≤0.5 和 B 站回执仍待完成。当前不支持多段 Range 或离线授权导出；不把这轮夹具播放算作整片质量通过。
