## 当前远端条件

2026-10-19 通过原路由配置中的已有信任 SSH（严格主机密钥检查、BatchMode）核对 `192.168.100.111`。Tesla V100-SXM2-16GB 实际占用 14917 MiB，剩余 1228 MiB；四个 `audiocpp_server` PID 为 528386、619358、665717、1370261。不能把一次 GPU 利用率 0% 当作设备归本项目所有或可随意卸载模型。

只读 `/v1/models` 返回：8080/8083 是已加载 IndexTTS2，8082 是已加载 Qwen3-ASR，8081 的 BS-RoFormer 当前未加载。所有现有进程均未被停止、卸载、替换或重启。已有同步任务接口可作为后续接入候选，但没有已验证的逐请求查询/取消协议；请求方断连后不能凭 HTTP 超时证明 GPU 计算结束。

对 8080 服务进一步通过 `/proc` 核对 PID 665717、启动 tick 15759724、实际监听 socket inode、执行器和模型文件摘要。实际执行器 SHA-256 为 `a30d89635b38784d22ea102219400e0a8529955c6eb9294eeaea55e7b7c69b4e`；权重 SHA-256 为 `5e827b2072042e4a1b21ccf24a5cb4f71cb1011403067a0a9b039311d8b38628`，与本机固定 IndexTTS2.5 Q8 GGUF 相同。启动 boot ID 留在私有证据中，公共证据仅保留其摘要。此次通过 SSH 在内存执行身份探针，**没有把它称为远端持久部署或实际 GPU 推理**；也不声称已复现该已有执行器的源码构建。

## 业务节点

新增 `apps/deep_dub/nodes/resident_job.py`，使用 Python 标准库，可作为未来远端业务 Worker 的单次执行节点；业务不烘焙进平台镜像。同步 HTTP 只连接本机明确 IPv4 监听地址，不读取代理、浏览器 Cookie 或调用者登录态。

- Linux 作业目录只能位于带本工作区标记的 `/opt/anp`，目录仅当前用户可访问。清单绑定唯一 UUID、固定模型 PID/启动时钟/boot ID/执行器/权重、参考 WAV 摘要和生成参数；用户会话和任意额外字段拒绝。
- 固定音色、逐段情绪与译稿分开绑定。只支持当前 IndexTTS2.5 参数范围；不接受跨作业音频路径、修改过的参考或未知选项。
- 每次进入前重查实际监听归属及已加载模型；不会启动、停止或卸载常驻服务。参考在身份检查后、完成响应后再次核验。
- 持有独占作业文件锁，持久化并 fsync `submit_intent` 后才发唯一 POST。重复进入已有状态只读回原状态，**即使上次可能在 POST 前退出也不自动补发**。
- 完整收到响应并再次核实身份后，才确认此请求已返回；非法 WAV 标记失败，断连、超时或身份变化保留 uncertain。仅在完整合法 WAV、样本及摘要落盘后记 succeeded。常驻服务始终不被标为已停止，质量始终 not_measured。
- 成功重放也校验产物存在、大小和 SHA，篡改拒绝，不通过重跑掩盖损坏。

这是一份远端执行协议的节点实现，**不是端到端远端调度器**。尚不能让 HTTP/CLI 直接任意提交此节点，也没有将它接入正式图或改变任何待审门禁。
