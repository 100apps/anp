# 平台剩余验收条件

状态：2026-10-18，平台固定摘要已通过本机启动与 85 项回归。以下条件不改写为已通过。

## DBX 下载

- 已运行验证：浏览器首次请求 `/dbx/api/export/database/download/<exportId>`，网关返回 200；随后 Chrome 显示 `ERR_BLOCKED_BY_CLIENT`。具体客户端拦截来源尚未确认。
- 已核实源码：下载处理器先从 `export_files` 移除导出 ID，再读取并删除临时文件。这是一次性下载，重试原 ID 会报文件不存在，不能据此判断最初导出失败。
- 已运行验证的替代路径：独立 HTTP 客户端在 `/dbx/api/auth/login` 登录，连接预置数据库，调用 `/dbx/api/export/database` 新建导出任务，完成后立即读取其独立下载 URL。表结构、视图定义和 5008 字符已保存值均出现在实际 SQL 文件中。文件 SHA、大小与验收范围见 `evidence/v3-ghcr-local-20261018.json`。
- 身份、Cookie 与导出 ID 不跨客户端复用；凭据只从私有配置读取。没有修改浏览器安全设置，也没有把下载变成公开链接。
- 限制：Chrome 直接保存文件没有通过验收。后续在用户可见浏览器中复验时需重新生成导出任务，不能重用已消费 ID。

本机私有配置未设置 `CLOUD_` 资源变量。目前只有 URL/凭据/TLS 绑定传播测试与本地四存储实测，没有真实云迁移结果。

实测需要用户提供的现有资源或另行授权创建的资源：独立测试数据库与具备迁移权限的账号、Redis 测试命名空间、ClickHouse 独立数据库与迁移/读写账号，以及 S3 私有测试桶和区域。连接必须带正确的 TLS 验证与服务端证书信任；托管服务需支持现有迁移所用扩展和协议。完整秘密仍只进入私有 env。
